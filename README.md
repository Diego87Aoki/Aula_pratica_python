# ☕ Estruturas de Controle em Java – Prática

Este repositório contém um programa em Java com exemplos práticos das principais **estruturas de controle de fluxo**, ideal para quem está iniciando na programação com Java.

---

## 📚 Conteúdo do Programa

### ✅ Verificação de Maioridade
- Utiliza `if-else` e operadores relacionais para verificar se a idade digitada é maior ou menor de 18 anos.

### 📅 Identificação do Dia da Semana
- Utiliza `switch-case` para identificar o dia da semana com base em um número de 1 a 7.

### ✖️ Tabuada do 5
- Usa laço `for` para imprimir a tabuada do número 5.

### 🔁 Contagem com While
- Mostra uma contagem simples de 0 até 4 com `while`.

### 🔂 Avaliação com Do-While
- Solicita notas repetidamente usando `do-while`, avaliando se o aluno está aprovado (nota ≥ 6) e perguntando se deseja continuar.

- ☕ Java (JDK 8 ou superior)
